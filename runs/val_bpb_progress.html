Every point is a val_bpb an actual run produced under one frozen scope (ophis_v3b_karpathy228791f_model_correctedbpb_pinned10_tokencache_h200_train300s): one H200, a fixed 300 s charged-training budget, corrected byte-fallback BPB. Nothing is normalised, fitted, or inferred. Only runs whose EvidenceDecision is valid are plotted, and 3 landed runs whose decision was not valid were excluded here — they remain in the immutable store, so nothing is deleted, only kept off a scale it does not belong on. The host is shared, so a candidate is only ever read against the exact bank control frozen into its spec before launch on the same physical GPU — both are plotted and joined by a line. The grey band is ±2σ of the control replicates: anything inside it is an unordered tie. Nothing on this chart is SOTA — promotion-due is a work-allocation decision, and only a held-out-seed confirmation can move the record.
